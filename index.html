Transparence

Sources, limites et méthode

WORLD RADAR agrège des titres et liens publics. GDELT est un index médiatique mondial, pas une agence de vérification. Le classement thématique et les niveaux d’alerte sont calculés localement à partir des titres : ils peuvent se tromper. Les articles restent la propriété de leurs éditeurs et s’ouvrent sur les sites d’origine.

Le flux de secours utilise l’affichage HTML officiel de GDELT dans un cadre intégré. Si une API ou un réseau bloque l’accès, les portails institutionnels et les recherches thématiques restent accessibles. Un site statique GitHub Pages ne peut pas garantir la disponibilité de services externes ni contourner les blocages réseau.

Données sismiques : USGS. Fond cartographique : OpenStreetMap. Articles : GDELT et liens vers les éditeurs. Pas de volcano-monitoring.
